# line-FOLLOWER-obot
This project details an autonomous Arduino line-following robot using a QTR-8RC IR sensor array and dual DC gear motors. Employing a multi-zone bang-bang algorithm, it navigates straight lines, curves, and 90° turns. Focus areas include sensor calibration, motor control, and line-loss recovery for reliable tracking across varied track layouts.
